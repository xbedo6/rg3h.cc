# رِجعة — RG3H.cc

نظام ولاء عربي: زيارات، خصومات ونقاط. لوحة إدارة، لوحة صاحب النشاط، شاشة الموظف وبطاقات العملاء. حتى ثلاثة برامج لكل نشاط، مع عملاء غير محدودين.

## التشغيل

Node.js 24. متغيرات التشغيل في `.env.example`، دون حفظ الأسرار في المستودع. الأمر: `node production.mjs`.

الموقع: https://rg3h.cc/، الإدارة: https://rg3h.cc/admin، فحص الخدمة: `/health`.

صاحب النشاط يدخل بالإيميل وكلمة المرور، مع كود بريد لتأكيد الحساب الجديد والاستعادة. الموظف يدخل باسم مستخدم ورمز من ستة أرقام يحددهما صاحب النشاط. يمكن لصاحب النشاط إعادة تعيين الرمز، فتُلغى جلسات الموظف القديمة. الإدارة تدخل بكود بريد حصريًا عبر `ADMIN_EMAIL`. إصدار بطاقة العميل بالاسم والجوال، دون SMS. إرسال البريد يستخدم Gmail API بصلاحية إرسال فقط؛ احفظ مفاتيح الربط في أسرار الاستضافة، ولا ترفعها إلى المستودع. لا تستخدم وضع الاختبار في الإنتاج. إصدار Apple/Google Wallet الفعلي ينتظر ربط الموفر.

## البيانات

قاعدة SQLite تبدأ دون حسابات أو عملاء تجريبيين. يجب ربط `DATA_DIR` بقرص دائم مع نسخة خادم واحدة قبل تشغيل حسابات العملاء. الاستضافة المجانية الحالية مخصصة للتجربة حتى تفعيل التخزين الدائم. تحفظ الجلسات والأكواد مجزأة، وكلمات المرور باستخدام scrypt. يحفظ رمز Gmail المشفر منفصلًا عن بيانات الأنشطة، ويجب تثبيته في `GMAIL_REFRESH_TOKEN` قبل أي إعادة نشر على قرص مؤقت.

## الاشتراك

199 ريال شهريًا، الدفع والتفعيل عبر واتساب. السعر السنوي بالتفاوض. الإدارة تفعل شهرًا أو سنة، توقف الحسابات وتصدر توكنات مرتبطة بالحساب لمرة واحدة.

## التحقق

اختبرت الواجهة المتصلة بالخادم، صلاحيات الحسابات، التفعيل، الموظفين، النقاط والخصومات، حد البرامج الثلاثة، التسجيل في البرامج الفرعية، عزل بيانات العملاء وإيقاف الاشتراك.

المكتبات الخارجية وتراخيصها داخل ملفات الواجهة: QR، jsQR، JsBarcode وZXing. الخط IBM Plex Sans Arabic عبر Google Fonts.
