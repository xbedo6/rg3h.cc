# رِجعة — RG3H.cc

نظام ولاء عربي: زيارات، خصومات ونقاط. لوحة إدارة، لوحة صاحب النشاط، شاشة الموظف وبطاقات العملاء. باقات بداية ونمو واحتراف: 1 و3 و10 برامج، و2 و5 و20 موظفًا، و1 و5 و20 فرعًا، مع عملاء غير محدودين.

## التشغيل

Node.js 24. متغيرات التشغيل في `.env.example`، دون حفظ الأسرار في المستودع. الأمر: `node production.mjs`.

الموقع: https://rg3h.cc/، الإدارة: https://rg3h.cc/admin، فحص الخدمة: `/health`.

صاحب النشاط يدخل بالإيميل وكلمة المرور، مع كود بريد لتأكيد الحساب الجديد والاستعادة. الموظف يدخل باسم مستخدم ورمز من ستة أرقام يحددهما صاحب النشاط. يمكن لصاحب النشاط إعادة تعيين الرمز، فتُلغى جلسات الموظف القديمة. الإدارة تدخل بكود بريد حصريًا عبر `ADMIN_EMAIL`. إصدار بطاقة العميل بالاسم والجوال، دون SMS. إرسال البريد يستخدم Gmail API بصلاحية إرسال فقط؛ احفظ مفاتيح الربط في أسرار الاستضافة، ولا ترفعها إلى المستودع. لا تستخدم وضع الاختبار في الإنتاج. إصدار Apple/Google Wallet الفعلي ينتظر ربط الموفر.

## البيانات

استعادة بطاقة العميل متاحة من صفحة مسح الموظف أو صفحة العملاء لدى صاحب النشاط. يلزم التحقق المباشر من هوية العميل وملكية رقم الجوال وتأكيد ذلك قبل إصدار الرابط. الرابط صالح لعشر دقائق ولمرة واحدة، ويُحفظ مجزأً في قاعدة البيانات؛ إصدار رابط جديد يُلغي السابق. فتح الرابط لا يستهلكه حتى يؤكد العميل الاستعادة. الاستعادة تحفظ الرصيد وتلغي جلسات البطاقة السابقة. لا يُعاد تسليم البطاقة بمجرد إدخال رقم الجوال في التسجيل العام.

رد العميل يتضمن بطاقته ورصيده فقط، دون بريد صاحب النشاط أو تفاصيل اشتراكه. معاينة الإدارة محصورة بالنشاط المختار، وتتحقق الأوامر من نطاق النشاط على الخادم. عند العودة للإدارة تُستعاد قائمة الأنشطة الكاملة.

قاعدة SQLite تبدأ دون حسابات أو عملاء تجريبيين. يجب ربط `DATA_DIR` بقرص دائم مع نسخة خادم واحدة قبل تشغيل حسابات العملاء. الخدمة على Render بخطة Starter وقرص دائم 1GB على /tmp/rijaa. تحفظ الجلسات والأكواد مجزأة، وكلمات المرور باستخدام scrypt. يحفظ رمز Gmail المشفر منفصلًا عن بيانات الأنشطة، ويجب تثبيته في `GMAIL_REFRESH_TOKEN` قبل أي إعادة نشر على قرص مؤقت.

## الاشتراك

99 و149 و299 ريال شهريًا حسب الباقة؛ الدفع والتفعيل عبر واتساب. السنوي 999 و1499 و2999 ريالًا لمدة 12 شهرًا؛ وصف الشهرين المجانيين يشير للتوفير في السعر ولا يضيف شهرين للمدة. الإدارة تختار الباقة وتفعل شهرًا أو سنة، توقف الحسابات وتصدر توكنات مرتبطة بالحساب لمرة واحدة.

## التحقق

اختبرت الواجهة المتصلة بالخادم، صلاحيات الحسابات، التفعيل، الموظفين، النقاط والخصومات، حد البرامج الثلاثة، التسجيل في البرامج الفرعية، عزل بيانات العملاء وإيقاف الاشتراك.

المكتبات الخارجية وتراخيصها داخل ملفات الواجهة: QR، jsQR، JsBarcode وZXing. الخط IBM Plex Sans Arabic عبر Google Fonts.
