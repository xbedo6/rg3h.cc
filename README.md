# رِجعة

نسخة عربية تفاعلية لنظام الولاء، مع أساس تشغيل من الخادم مختبر محليًا. افتح الموقع من خادم محلي، وليس بالنقر على ملف HTML، حتى تعمل الكاميرا والتخزين كما ينبغي.

إذا كان Node.js مثبتًا، نفذ `node server.cjs` ثم افتح `http://127.0.0.1:4317`.

رمز التحقق التجريبي: `123456`.

المعاينة على المنفذ 4317 تحفظ البيانات محليًا فقط، ولا ترسل SMS أو تصدر بطاقات Wallet فعلية. الدخول بها تمثيلي. في `production.mjs` يوجد مسار بديل للبيانات والجلسات والصلاحيات من الخادم وموصل Twilio Verify. راجع `rijaa-launch-readiness.md` قبل التشغيل؛ تكامل Wallet والنشر والتحقق من الرسائل الفعلية ما زال متبقيًا.

لتشغيل الخادم بعد تعبئة `.env` طبقًا لـ `.env.example`: `node --env-file=.env production.mjs` باستخدام Node 24. لا تنشر وضع SMS الاختباري. استضافة SQLite تتطلب قرصًا دائمًا ونسخة خادم واحدة. لا تنقل أسرار التشغيل أو ملفات قاعدة البيانات داخل المصدر العام.

المكونات الخارجية: qrcode-generator 1.4.4 وjsQR 1.4.0، مع تراخيصها داخل ملفات المصدر. خط IBM Plex Sans Arabic من Google Fonts.
